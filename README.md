# Agrim Srivastava - Portfolio

Static, dependency-light portfolio site built with GSAP and responsive typography. The design features a continuous narrative scroll across systems, projects, research, and technical background.

## Live Site

Published via GitHub Pages: [https://agrimsri.github.io](https://agrimsri.github.io)

## Local Preview

Open `index.html` directly in any modern browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Architecture & Design Notes

- Self-contained, dependency-light static architecture with zero build step.
- Scroll-choreographed experience powered by GSAP and ScrollTrigger.
- Responsive typography with Instrument Serif, DM Sans, and DM Mono.
- Accessible navigation and keyboard-friendly focus management.
- Optimized portrait assets rendered in WebP with dithering fallback.
